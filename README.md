# Traffic Accident Analysis and Prevention Framework

## Overview
This framework leverages the 'Traffic Accident Reports in Abu Dhabi Dataset 2025' to provide actionable insights for policymakers, urban planners, and researchers. By utilizing advanced analytics and machine learning, the framework identifies high-risk areas, common accident causes, and temporal patterns to improve road safety.

## Features
1. **Accident Trend Analysis**: Analyze traffic accident trends over different periods.
2. **Geospatial Mapping**: Visualize accident hotspots on an interactive map.
3. **Cause Analysis**: Identify contributing factors to traffic accidents.
4. **Predictive Modeling**: Use machine learning to predict potential accident hotspots.
5. **Stakeholder Reporting**: Generate tailored reports for various stakeholders.

## Requirements
- Python 3.8+
- Pandas
- Folium
- Scikit-learn

## Installation
1. Clone the repository:
    bash
    git clone https://github.com/your-repo/traffic-accident-analysis.git
    cd traffic-accident-analysis
    
2. Install dependencies:
    bash
    pip install pandas folium scikit-learn
    

## Usage
1. Place the dataset file `Traffic_Accident-v3.0_AbuDhabi_2025.xlsx` in the project directory.
2. Run the script:
    bash
    python traffic_analysis.py
    
3. Open the generated `accident_hotspots_map.html` file in a web browser to view accident hotspots.

## Output
- **Model Accuracy**: Displays the accuracy of the trained machine learning model.
- **Interactive Map**: Visualizes accident hotspots.
